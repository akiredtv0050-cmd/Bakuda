効果音（mp3）の置き場所です。
次の名前で置くと、その音が鳴ります（無い音は 電子音で代わりに鳴ります）：
tap open close change hit defeat craft levelup timeover error get anvil ＋ .mp3

今ある音は tools/gen_audio.py で 自動で作った「仮の音」です（ぜんぶ プログラムで 計算した音）。
チームの音ができたら、同じ名前で 上書きしてください。
  tap … ボタン   open/close … 画面をひらく/とじる   change … きりかえ   hit … たたく
  defeat … たおした   craft … 完成   levelup … レベルアップ・大成功   timeover … 時間ぎれ・失敗
  error … できない   get … 手に入れた   anvil … 鍛冶のハンマー「カーン！」
