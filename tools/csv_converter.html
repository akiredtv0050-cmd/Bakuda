📋 スプレッドシート → データ変換ツール

Googleスプレッドシートの表をコピーして貼り付けると、ゲーム用のデータファイル（data/ フォルダの .js）を作ります。
このページは ダブルクリックで開くだけ で使えます（インストール不要）。シートに無い項目（画像名・絵文字など）は、今のデータファイルから引き継ぎます。

1どのシート？
2シートを貼り付け （シートを開いて Ctrl+A → Ctrl+C → ここで Ctrl+V）／ CSV・TSVファイルを選んでもOK
3変換
📖 使い方・列の名前

・1行目に No. がある行を「見出し」として読みます。見出しの名前は英語・日本語どちらでもOK。
・weapon / accessory は今のシートと同じ「種類ごとに横に並んだ表」に対応しています。見出しの1行上に種類名（スティック、杖…）を書いてください。
・できたファイルを data/ の同じ名前のファイルと入れ替えれば完了です（weapon なら data/weapons/ に10個）。

データの項目見出しに使える名前
noNo. / No / 番号 / 段階
nameName / 名前
atkattacks / atk / 攻撃力
descSummary / 説明
areaArea No. / Area / エリア
costmaterial / 素材 / 必要素材 （例：ヒノキの木材×3, ヒノキのつる×2）
hp / timeHP / time / 制限時間
dropDrop / ドロップ
level / themeLevel / レベル ／ theme / テーマ
image / iconimage / 画像 ／ icon / sprite / 絵文字
