# 開発の記録（公開前）

公開版 v1.0.0 より前の、開発中のバージョン記録です。

- エリアに入れるレベルを10ずつに → 公開版では15ずつに変更

- レベルが上がりやすくなるように調整

- エリア移動を「地方の島 → 3つのエリア」に
- 鍛冶マップの形を種類ごとにランダムに
- アクセサリーを全55段階に
- 地方ごとのエリア名公開、もちものフィルター、種類ボタンのスライド
- デバッグボタン削除、メインメニューの文字を見やすく
