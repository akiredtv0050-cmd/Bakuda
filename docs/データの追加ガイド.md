# データの追加ガイド（くわしく版）

このゲームは「**データファイルに1行書く ＋ 決まった名前で画像を置く**」だけで中身が増えるように作ってあります。
プログラム（`js/` フォルダ）をさわる必要はありません。

---

## 0. まず知っておくこと

### 0-1. ものどうしの「つながり」

```
 エリア（areas.js）
   ├─ モンスター（monsters.js）── drop ──┐
   └─ オブジェクト（objects.js）── drop ─┤
                                          ▼
                                    素材（materials.js）
                                          │ cost（必要素材）
                                          ▼
                       武器（weapons/*.js）・アクセ（accessories/*.js）
```

- モンスター・オブジェクトは **エリア** に出てきて、倒すと **素材** を落とします（`drop`）。
- 武器・アクセは **素材** を使って作ります（`cost`）。
- つながりは **名前の文字** で決まります。`drop: 'ヒノキの木材'` と `materials.js` の `name: 'ヒノキの木材'` は **1文字もちがわないように** してください（全角・半角、ひらがな・カタカナもちがいになります）。

### 0-2. 追加のやり方は2つ

| やり方 | 向いているとき |
|---|---|
| **A. スプレッドシートから変換**（`tools/csv_converter.html`） | たくさん一気に足すとき。チームで案を出しているとき |
| **B. データファイルを直接書く**（メモ帳・VS Code など） | 1つ2つ足すとき。細かい項目（絵文字・画像名など）を決めるとき |

どちらでも結果は同じです。A でシートに無い項目（画像名・絵文字など）は、今のファイルから自動で引き継がれます。

### 0-3. 書き方の基本ルール（直接書くとき）

```js
  { no: 11, name: 'もりのくま', area: 2, drop: 'トネリコの木材', desc: '森の主。' },
```

- 1つのもの＝`{ }` の1行。行の最後に **`,`（半角カンマ）** を忘れずに。
- 文字は `'` `'`（半角シングルクォート）でかこむ。数字はそのまま（`hp: 30`）。
- 文字の中に `'` を使いたいときは `\'` と書く。
- 書かなかった項目・空欄（`''`）は **自動で決まる** か **「じゅんび中」** になります。
- 保存したら `index.html` を開き直す（ブラウザの再読み込み）だけで反映されます。

> うまく動かないときは、まず `tools/asset_checker.html` を開いて「⚠ データの注意」を見てください。
> 名前のまちがい・番号の重なりを教えてくれます。画面が真っ白なら、カンマや `'` の書き忘れがほとんどです（F12 → Console に赤い文字で場所が出ます）。

## 1. モンスターを足す（`data/monsters.js`）

### 手順
1. `data/monsters.js` の最後の行の下に1行足す
2. 画像を `assets/images/monster/` に置く
3. 落とす素材がまだ無ければ、`data/materials.js` にも足す（→ 3章）

### 例
```js
  { no: 11, name: 'もりのくま', area: 2, time: 12, drop: 'トネリコの木材', sprite: '🐻', desc: '迷いの森林の主。力もち。' },
```

| 項目 | 意味 | 書かなかったら |
|---|---|---|
| `no` | 番号（他のモンスターと重ならない数字） | **必須** |
| `name` | 名前 | **必須** |
| `area` | 出てくるエリアの番号（1〜55） | エリア1 |
| `hp` | 体力 | エリアが進むほど強くなる式で自動（`balance.js` の `targetHp`） |
| `time` | 制限時間（秒）。0 にすると時間制限なし | 10秒 |
| `drop` | 倒すと手に入る素材の **名前** | 何も落とさない |
| `sprite` | 画像が無いときに代わりに出す絵文字 | 👾 |
| `image` | 画像ファイル名 | `monster_011.png`（`monster_` ＋ No.3桁） |
| `desc` | 図鑑の説明 | 空 |

### 画像
- 置き場所：`assets/images/monster/`
- 名前のつけ方は2通り。どちらでもOK
  - **自動名**：`monster_011.png`（No.11 なら）→ `image` は書かなくてよい
  - **好きな名前**：`kuma1.png` → データに `image: 'kuma1.png'` と書く
- 背景は透明、256×256px 以内がおすすめ

### 確認
冒険 → 🗺️エリア → そのエリアへ行く → ⚔️たたかう。何回か「⏩つぎ」を押すと出てきます（ランダム）。倒すと図鑑の「モンスター」にのります。

## 2. オブジェクト（こわすもの）を足す（`data/objects.js`）

モンスターとほぼ同じです。ちがいは **制限時間が無い**（`time` は使わない）ことだけ。

```js
  { no: 11, name: 'トネリコの若木', area: 2, drop: 'トネリコの木材', sprite: '🌳', desc: '細くてよくしなる木。' },
```
- 画像：`assets/images/object/`（自動名は `object_011.png`）
- 冒険画面の「⛏️さがす」で出てきます。

## 3. 素材を足す（`data/materials.js`）

```js
  { no: 24, name: 'くまのツメ', area: 2, icon: '🐾', desc: 'もりのくまの大きなツメ。' },
```

| 項目 | 意味 | 書かなかったら |
|---|---|---|
| `no` | 番号（重ならない数字） | **必須** |
| `name` | 名前（モンスターの `drop`、武器の `cost` と同じ文字にする） | **必須** |
| `area` | 主に手に入るエリア | エリア1 |
| `icon` | 画像が無いときの絵文字 | 📦 |
| `image` | 画像ファイル名 | `mat_024.png` |
| `desc` | 説明 | 空 |

### ⚠ 素材は「落とすもの」を決めないと手に入りません
素材を足したら、必ずどれかのモンスターかオブジェクトの `drop` にその名前を書いてください。
`area` の素材を誰も落とさないと、そのエリアの武器は「ひつような そざい が まだ決まっていません」で作れません。

- 画像：`assets/images/mat/`

## 4. 武器を足す（`data/weapons/◯◯.js`）

武器は **種類ごとに1ファイル**、どのファイルにも **No.1〜165 の行がもう全部用意されています**。
**空いている行の `name` を埋めるだけ** です（行を新しく足す必要はありません）。

| ファイル | 種類 | | ファイル | 種類 |
|---|---|---|---|---|
| `stick.js` | スティック | | `tume.js` | 爪 |
| `tue.js` | 杖 | | `ono.js` | 斧 |
| `wip.js` | 鞭 | | `mace.js` | メイス |
| `daga.js` | 短剣 | | `kama.js` | 鎌 |
| `ken.js` | 剣 | | `taiken.js` | 大剣 |

### No. とエリアの関係（3つずつ）
| No. | エリア | | No. | エリア |
|---|---|---|---|---|
| 1〜3 | 1 始まりの平原 | | 10〜12 | 4 乾燥した砂漠 |
| 4〜6 | 2 迷いの森林 | | … | … |
| 7〜9 | 3 深緑の森 | | 163〜165 | 55 魔王城（玉座） |

計算：**エリア = (No. + 2) ÷ 3 の整数部分**。そのエリアに行けるようになると作れます。

### 例（`ken.js` の No.4 を埋める）
```js
  { no: 4, name: 'もりのつるぎ', desc: '森の木で作った軽い剣。' },
  // 必要素材も自分で決めたいとき
  { no: 5, name: 'くまさんソード', atk: 12, cost: 'くまのツメ×3, トネリコの木材×2', desc: '…' },
```

| 項目 | 意味 | 書かなかったら |
|---|---|---|
| `no` | 段階（1〜165） | 用意済み |
| `name` | 名前。**空欄だとその段階は「じゅんび中」で作れない・図鑑にものらない** | じゅんび中 |
| `atk` | 攻撃力 | 段階が上がるほど強くなる式で自動 |
| `cost` | 必要素材。`'名前×個数, 名前×個数'` の形 | そのエリアで手に入る素材から自動 |
| `image` | 画像 | 自動名（下を見てね） |
| `desc` | 説明 | 空 |

### 画像
- 置き場所：`assets/images/weapon/{種類}/`
- 名前：`{種類}_{No.3桁}.png` → 剣の No.4 なら **`assets/images/weapon/ken/ken_004.png`**
- 画像を置くだけで、鍛冶マップ・図鑑・装備・冒険画面ぜんぶに出ます。

## 6. エリアを変える（`data/areas.js`）

エリアは55か所ぶん **もう全部あります**。名前や見た目を変えるときに使います。

```js
  { no: 4, name: '乾燥した砂漠', theme: 'desert', desc: '…', bg: 'assets/images/bg/bg_desert1.png', bgm: 'assets/bgm/field_desert.mp3' },
```

| 項目 | 意味 | 書かなかったら |
|---|---|---|
| `theme` | 見た目のテーマ（下の表） | grass |
| `level` | 入れるタップLv | **（No.−1）×15**（平原0、森15、森林30、砂漠1は45、砂漠2は60…） |
| `bg` | 冒険画面の背景 | テーマの背景 `bg_{テーマ}.png`（無ければ草原） |
| `bgm` | 冒険画面のBGM | テーマの曲 `field_{テーマ}.mp3`（無ければ草原の曲） |
| `mapImage` | 鍛冶マップの島のイラスト | 色つきの島 |

テーマ：`grass` 草原 / `forest` 森 / `desert` 砂漠 / `mountain` 山 / `cave` 洞窟 / `crystal` 水晶 / `beach` 海辺 / `sea` 海 / `snow` 雪 / `volcano` 火山 / `sky` 空 / `sweets` おかし / `poison` 毒 / `bigtree` 巨大樹 / `mushroom` キノコ / `earth` 大地 / `ghost` 霊 / `machine` 機械 / `space` 宇宙 / `magic` 魔法 / `ruins` 遺跡 / `demon` 魔王城

### 背景・BGMは「テーマで共通」が楽
`assets/images/bg/bg_desert.png` を1枚置けば、`theme: 'desert'` のエリア（砂漠1〜3）全部の背景になります。
エリアごとに変えたいときだけ `bg` を書いてください。BGM も同じ（`assets/bgm/field_desert.mp3`）。
背景画像のサイズ・ファイル名の一覧・ストーリーの背景は **`docs/背景画像の追加ガイド.md`** にまとめています。

### 入れるレベルを全体的に変えたい
`data/balance.js` の `areaLevelStep: 15` を変えると全部まとめて変わります（例：10 にすると 0, 10, 20, 30…）。くわしくは `docs/レベルの上がり方.md`。
1つのエリアだけ変えたいときは、そのエリアに `level: 35` のように書きます。

## 7. 地方（エリアのまとまり）を変える（`data/regions.js`）

エリア移動の「地方の島」と、エリア名の公開（地方の最初のエリアに行けると、3つとも名前が見える）に使います。

```js
  { no: 2, name: '灼熱の砂漠地方', theme: 'desert', areas: [4, 5, 6], desc: '砂と太陽とピラミッドの国。' },
```
- `areas` に入れたエリアが1つの地方になります（4つ以上でもOK。魔王城は4つ）。

## 8. 武器・アクセの「種類」を増やす（例：槍）

1. `js/core/config.js` の `WEAPON_TYPES` に1行足す
   ```js
   { id: 'yari', name: '槍', icon: '🔱', atkMul: 1.10, color: '#44aa99' },
   ```
   - `id`：半角英小文字（ファイル名・画像フォルダ名になる）　`atkMul`：攻撃力の倍率（1.0 が基準）
2. `data/weapons/stick.js` をコピーして `data/weapons/yari.js` にし、中の `registerWeapons('stick'` を `registerWeapons('yari'` に、名前を全部空欄にする
3. 画像フォルダ `assets/images/weapon/yari/` を作る

`index.html` を書きかえる必要はありません（種類の一覧から自動で読み込まれます）。鍛冶屋の種類ボタンにも自動で出ます。
アクセの種類なら `ACC_TYPES` と `data/accessories/` で同じことをします。

4. （武器だけ）たたいたときの「ふりかた」を `js/screens/adventure.js` の `SWING_STYLE` に1行足す
   ```js
   yari: 'stab',
   ```
   - `swing`（ふりおろし）/ `smash`（たたきつけ）/ `stab`（つき）/ `claw`（ひっかき）/ `magic`（まほう）/ `whip`（しなる）から選ぶ。書かなければ `swing`。

## 9. スプレッドシートから一気に変換する（`tools/csv_converter.html`）

1. スプレッドシートで該当のシート（weapon / accessory / stage / material / monster / object）を開く
2. **Ctrl+A → Ctrl+C**
3. `tools/csv_converter.html` をダブルクリックで開く → シートの種類を選ぶ → 貼り付け → 「🔄 変換する」
4. 「⬇️ ダウンロード」したファイルを `data/`（武器なら `data/weapons/`）の同じ名前のファイルに上書き

### シートの見出し（1行目）に使える名前
| 項目 | 見出しの名前 |
|---|---|
| no | No. / 番号 |
| name | Name / 名前 |
| atk | attacks / 攻撃力 |
| desc | Summary / 説明 |
| area | Area No. / エリア |
| cost | material / 素材 / 必要素材 |
| hp / time | HP / 制限時間 |
| drop | Drop / ドロップ |
| level / theme | Level / テーマ |
| image / icon | 画像 / 絵文字 |

> **お願い**：今の monster / object シートには「Area No.」の列がありません。足してください（無いと全部エリア1になります）。
> HP・制限時間・画像・絵文字の列も足すと、シートだけで全部決められます。

## 12. 新しいバージョンを出すとき

1. `js/core/config.js` の `version`（例 `'v1.1.0'`）
2. `sw.js` の `CACHE_NAME`（例 `'bakuda-craft-v1.1.0'`）← これを変えないと、スマホに古い画面が残ることがある
3. `data/changelog.js` のいちばん上にアップデート内容を追加（設定画面の「📢 アプデじょうほう」に出る）

## 12.5 隠しコマンドを足す（`data/secret_codes.js`）

設定 →「🔑 かくしコマンド」で入力すると、ごほうびがもらえます（画面の中の入力らんで入力。ブラウザのポップアップは出ません）。

```js
  { code: 'ばくだれんせい', once: true, reward: { mats: 5 }, msg: '全部の そざい を 5こずつ もらった！' },
  { code: 'TATAKE', once: true, reward: { level: 5 }, msg: 'タップレベルが 5 あがった！' },
  { code: 'KAJIYA', once: true, reward: { mats: { 'じょうぶな木': 20 } }, msg: '…' },
```
- 大文字・小文字、全角・半角、ひらがな・カタカナ は同じとして扱います。
- `once: true` で1人1回だけ。イベントやSNSで配るのに使えます。

## 12.6 ストーリーを書きかえる（`data/story.js`）

### あらすじ（全41シーン・約500セリフ）
千年まえ、まおうを ふういんした「はじまりの ほのお」。その さいごの ひのこ＝**ひばな** と、みならい かじやの **きみ** が、まおうゼノグリムの「さびの のろい」から せかいを すくう おはなし。
- **ゆうしゃレオン**：まおうに まけて けんが くだけた ゆうしゃ。きみの ぶきで もういちど たたかう やくそくを する。
- **クロガネ**：親方の むかしの 弟子。くろい ほのおで まおうの ぶきを つくる ライバル → なかまに。
- 各地方で 出会う なかま：まじんファラク（砂漠）・ゴルド（山）・シズク（海）・ユキ（雪）・エント（巨大樹）・ポム（キノコ）・いにしえの かじや（霊）・ギアっこ（からくり）
- 大きな なぞ：ピラミッドの 絵（2章）→ ひばなの正体（12章）→ 「ほのおを やどすと きえる」（10・13章）→ さいごの たたかい → エンディング → エピローグ

### いつ流れるか
| 名前 | タイミング |
|---|---|
| `prologue` | はじめて「はじめる」を押したとき |
| `first_craft` | はじめて きたえて「完成！」を とじたとき |
| `first_great` | はじめて ミニゲームで 大成功したあと |
| `region_1`〜`region_18` | その地方に はじめて行ったとき（章のはじまり） |
| `clear_1`〜`clear_17` | その地方の さいごのエリアの「ぬし」を はじめて たおしたとき（章のおわり） |
| `boss` | まおうが はじめて出たとき |
| `ending` → `epilogue` | まおうを たおしたとき → スタッフロールのあと |

「📜 おはなし」の ならび順と、アップデートまえから遊んでいる人が 見られる条件は、同じファイルの `STORY_TRIGGERS` です。

### 書き方
```js
  region_2: {
    title: '第2章　灼熱の砂漠', sub: 'ねむれる まじんの いし',
    lines: [
      ['きみ', 'あ、あつい……！'],
      ['魔王の声', 'フハハハ……。', 'dark shake'],     // 3つ目は演出
      ['', 'これは ナレーション（語り）'],
    ]
  },
```
- `lines` の1つ目は話す人（`STORY_CHARS` の名前）。`''` だとナレーション。
- 背景は自動でその章のエリアになります（`region_N` は地方のさいしょのエリア、`clear_N` はさいごのエリア）。シーンに `area: 番号` や `bg: '画像'` を書けば変えられます。プロローグなどは `STORY_BG`。
- 3つ目（なくてもOK）は演出：`shake`（ゆれる）`flash`（白く光る）`dark`（暗く赤く）`glow`（あたたかく光る）`big`（文字が大きい）。スペースで いくつでも。
- `{weapon}` と書くと、そのときの武器の名前になります。
- 登場人物を増やすときは `STORY_CHARS` に1行。顔の絵は `assets/images/story/` に置いて `image:` を書く。
- エンディングのスタッフロールは同じファイルの `ENDING_CREDITS` を書きかえてください。
- エンディングの曲は `assets/bgm/ending.mp3` を置くと流れます（無いときはタイトルの曲）。

## 12.8 鍛冶のミニゲーム（`js/forge/minigames.js`）

「🔨 きたえる！」を押すと、8しゅるいの中から ランダムで1つ遊びます（同じものが2回つづかない）。

| けっか | できばえ | 攻撃力 |
|---|---|---|
| 失敗 | ふつう | ×1 |
| 成功 | ★ | ×1.5 |
| 大成功 | ★★ | ×2 |

- 倍率は `js/core/player.js` の `QUALITY` で変えられます。できばえはアイテムごとにセーブされ、そうび・図鑑・鍛冶の画面に ★ で出ます。
- むずかしさは、きたえる武器のエリアで上がります（エリア1で 1.0 → エリア55で 1.6）。`MG.play()` の `d:` の式で調整。
- はじめて遊ぶゲームは くわしいルール、2回目からは 1行の説明だけ。「ミニゲームなしで きたえる」を押すと ふつう（×1）で作れます。
- PC は スペース / Z / Enter でも遊べます（長おしのゲームは キーを おしっぱなし）。

| id | 名前 | 内容 |
|---|---|---|
| strike | 打ちこみタイミング | 動く線を オレンジの所で止める ×5（PERFECT 4回で大成功） |
| heat | 火加減キープ | 長おしで 温度を 動く緑のはんいに たもつ（10秒） |
| quench | 焼き入れ | 変わっていく 金属の色が お手本と同じ時に タップ ×3 |
| rune | ルーンの記憶 | 光った じゅんばんを おぼえて タップ（3ラウンド） |
| rhythm | リズム鍛造 | ちぢむ輪が 金床に かさなった時に タップ ×8 |
| whack | 不純物はじき | 黒い石だけ タップ、宝石は さわらない（14秒で12こ） |
| gauge | ぴったり配合 | 長おしで そそいで 赤い線で はなす ×3 |
| pairs | 刻印あわせ | 同じ刻印の カードを そろえる（6組） |

### 打ち込みやり直し
- いちど作った武器・アクセは、鍛冶のパネルに「🔁 打ち込みやり直し」ボタンが出ます。
  - 出る条件：**作ってある ＆ まだ大成功（★★）ではない ＆ 同じ素材が そろっている**（`Player.canReforge`）
  - 押すと 同じ素材を使って ミニゲーム → **いまより よいけっかの時だけ** できばえが上がります（失敗しても 下がりません）。
  - ミニゲームの はじめの画面で「やめる」を押すと、素材は へりません。
- 回数は `S.stats.reforges` に記録されます（実績を足すときに使えます）。

### ミニゲームを足すとき
`MINIGAMES` に1つ足すだけです（どこにも登録はいりません）。
```js
  mygame: {
    ico: '🧲', name: 'なまえ', short: '2回目からの 1行説明',
    rule: 'はじめての ときの ルール説明（<b>強調</b> も使える）',
    start(a, P) {               // a = 道具、P.d = むずかしさ
      a.el({ left: '10px', top: '10px', fontSize: '40px' }).textContent = '🧲';   // 絵を置く
      return {
        update(dt) { /* 毎フレーム */ },
        act() { a.end('great'); }       // タップ（down/up を書くと 長おし・場所つきタップ）
      };
    }
  },
```
道具：`a.W` `a.H`（広さ）/ `a.el(css)`（部品を置く）/ `a.say(文)` / `a.prog(0〜1)` / `a.hud(文)` / `a.flash(文, 色)` / `a.timer(fn, ミリ秒)` / `a.end('fail'|'good'|'great')`
実績「なんでも こなす」（`mgall`）の数（8）も合わせて変えてください。

## 12.9 仮の絵・仮の音を 自動で作る（`tools/gen_*.py`）

絵が まだ無い番号に、名前とエリアから よそうした「仮の絵」を作るツールです。**すでにある絵は 上書きしません。**

| ツール | 作る絵 | 一覧ファイル |
|---|---|---|
| `tools/gen_item_images.py` | 武器・アクセ | `tools/items.json` |
| `tools/gen_target_images.py` | モンスター・オブジェクト・素材 | `tools/targets.json` |
| `tools/gen_bg_images.py` | エリアの背景（テーマごと） | いらない |
| `tools/gen_audio.py` | 効果音（SE）・エリアのBGM・エンディングの曲 | いらない（ffmpeg が必要） |

1. データ（`data/*.js`）を変えたら、`tools/asset_checker.html` を開いて「📄 …一覧を保存」を押し、保存した json を `tools/` に置く
2. `python tools/gen_item_images.py tools/items.json` のように 実行（Python 3・Pillow・numpy が必要）
3. 名前の言葉で 形や色が決まります（例：「こおり」→ 水色、「まおう」→ 赤黒、「スライム」→ スライムの形）。
   言葉と形の表は、各ツールの上のほう（`KEYWORDS` / `MON_SHAPE` / `TINT` など）にあります。

ライセンスなどは `assets/images/README_仮の絵.txt` を見てください。
音は ぜんぶ プログラムで 計算した音なので、借りものの素材は ありません。曲の ふんいき（テンポ・調・楽器・ドラム）は `tools/gen_audio.py` の `SONGS` で変えられます（`--only=bgm --force` で作りなおし）。

## 13. よくあるまちがい

| こまったこと | 原因 |
|---|---|
| 画面が真っ白 | `,` や `'` の書き忘れ。全角の `，` `’` を使っている |
| 画像が絵文字のまま | ファイル名・フォルダのまちがい（`ken_4.png` ではなく `ken_004.png`）。大文字小文字もちがいになる |
| 武器が「じゅんび中」 | `name` が空欄 |
| 「ひつような そざい が まだ決まっていません」 | そのエリアの素材を、どのモンスター・オブジェクトも `drop` していない |
| モンスターが出てこない | `area` の番号ちがい。または ⚔️たたかう／⛏️さがす の切りかえ |
| 素材の名前の注意が出る | `drop` や `cost` の名前が `materials.js` の名前と1文字ちがう |

## 14. 開発のルール
- **お知らせ・確認は、すべてゲーム画面の中に出す。** ブラウザの `alert()` `confirm()` `prompt()` や、画面の上からすべり出る通知は使わない。
  - 確認したいとき：`UI.confirm({ title, html, ok, cancel })`
  - 伝えるだけ：`UI.alert(title, html)`
  - 結果を見せる：鍛冶の「できた！」画面のように、専用のポップアップを作る
