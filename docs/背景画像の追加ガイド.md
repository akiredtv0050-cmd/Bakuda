# 背景画像の追加ガイド

背景画像は **`assets/images/bg/`** に置きます。
**決まった名前で置くだけ**で使われるので、プログラムを書きかえる必要はありません（エリアごとに別の絵にしたいときだけ、`data/areas.js` に1行足します）。

---

## 1. 画像のきまり

| 項目 | おすすめ | 今ある画像 |
|---|---|---|
| 向き | **たて長**（スマホの画面と同じ） | たて長 |
| サイズ | **896×1200**（3:4）。最低 720×960 | 896×1200（タイトル・図鑑は 1792×2400） |
| 形式 | **PNG**（ドット絵がにじまない） | PNG |
| ファイルの大きさ | **1枚 500KB 以下**が目標 | 2.5〜6.6MB（重いので、あとで縮めるのがおすすめ） |
| 名前 | 半角の英小文字・数字・`_` だけ（日本語・大文字・スペースは使わない） | |

- 画面の大きさに合わせて、**はしが少し切れます**（パソコンの横長画面では上下、細長いスマホでは左右）。大事なものは**まん中**にかいてください。
- **冒険画面**では、まん中にモンスター、下の 1/3 に「れんだゾーン」やボタンが重なります。**まん中〜下はごちゃごちゃさせない**と見やすくなります。
- **ストーリー**では、下の 1/4 に会話のウィンドウが重なります。上半分に、その場所らしいもの（山・お城・火山など）をかくと雰囲気が出ます。

### C. ストーリーの背景
ストーリーが流れているあいだは、その場所の背景が うしろに出ます。左上に「📍 場所の名前」も表示されます。

| おはなし | 背景 |
|---|---|
| 第◯章のはじまり（`region_N`） | その地方の**さいしょ**のエリア（例：第3章 → 7 険しい山岳） |
| 第◯章のおわり（`clear_N`） | その地方の**さいご**のエリア（例：第3章 → 9 水晶の鍾乳洞） |
| まおうゼノグリム（`boss`） | 55 魔王城（玉座） |
| プロローグ・はじめての鍛冶・はじめての大成功 | `bg_craft.png`（ガンテツのかじや） |
| エピローグ | `bg_menu.png`（はじまりの村） |
| エンディング | 背景なし（エンディング画面の夜明けの空が見えます） |

## 3. 追加のしかた

### ① テーマの背景を足す（いちばんかんたん・おすすめ）
1. 上の表のファイル名で画像を作る（例：`bg_volcano.png`）
2. `assets/images/bg/` に置く
3. おわり！　火山の3エリアの冒険画面と、第6章のストーリーの背景が変わります。

### ② エリアごとに ちがう背景にする
同じテーマでも、エリアごとに絵を変えたいとき（例：砂漠の3つを全部ちがう絵にしたい）。

1. 好きな名前で画像を置く（例：`bg_pyramid.png`）
2. `data/areas.js` の そのエリアの行に `bg:` を足す
   ```js
   { no: 6, name: '焼けつくピラミッド', theme: 'desert', desc: '…', bg: 'assets/images/bg/bg_pyramid.png' },
   ```
   `bg:` を書いたエリアは、テーマの背景より こちらが優先です。書かなかったエリアは、テーマの背景のままです。

### ③ 新しいテーマを作る
1. `js/core/config.js` の `AREA_THEMES` に1行足す
   ```js
   jungle: { label: 'ジャングル', icon: '🌴', color: '#5fbf5a', dark: '#2a7a30' },
   ```
   - `color` / `dark` … 鍛冶マップの島の色と、背景が無いときのグラデーションの色
2. `assets/images/bg/bg_jungle.png` を置く
3. `data/areas.js` で使いたいエリアを `theme: 'jungle'` にする

### ④ ストーリーの背景を変える
- **章のストーリー**は、エリアの背景が変われば自動で変わります。
- 特定のシーンだけ別のエリアにしたいときは、`data/story.js` のそのシーンに `area: 番号` を書きます。
  ```js
  clear_11: { title: '第11章　おわり', sub: 'ふたりの みならい', area: 1, lines: [ … ] },
  ```
- エリアと関係ない画像にしたいときは `bg: '画像のパス'`。背景を出したくないときは `bg: 'none'`。
- プロローグ・エピローグなどは、`data/story.js` の `STORY_BG` で決めています。

### ⑤ 画面の背景（タイトル・メニューなど）を差しかえる
同じ名前で上書きするだけです（`bg_title.png` / `bg_menu.png` / `bg_craft.png` / `bg_zukan.png`）。

## 4. 置いたあとのチェック
1. `tools/asset_checker.html` をダブルクリック →「チェック開始」
   - 「ない」画像と、**大きすぎる画像（たてか横が 1400px より大きい）** が一覧で出ます（タイトル・図鑑の 1792×2400 も ここに出ます）。KB の大きさは パソコンの「プロパティ」で見てください。
2. ゲームを開いて、そのエリアに行ってみる（テストでレベルを上げたいときは「データの追加ガイド」11章）。
3. 「📜 おはなし」から、その地方のストーリーを見なおして、背景を確認する。

### うまく出ないとき
| こまったこと | 原因 |
|---|---|
| 草原の背景のまま | ファイル名のまちがい（`bg_Volcano.png` ✕ → `bg_volcano.png` ○）。`.PNG` と `.png` も ちがうファイルになる |
| ストーリーが色だけ | 同じく ファイル名のまちがい。またはフォルダが `assets/images/bg/` ではない |
| 表示がおそい・重い | 画像が大きすぎる。896×1200・500KB 以下に縮める |
| 文字やモンスターが見にくい | 背景のまん中〜下が明るすぎる・細かすぎる。少し暗く・シンプルにする |
