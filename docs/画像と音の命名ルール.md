# 画像と音の命名ルール

ゲームは **ファイル名から自動で画像を探します**。2000枚以上あっても、データに画像パスを1つずつ書く必要はありません。
名前を守って置くだけで表示されます（無いときは絵文字で代わりに表示）。

## 武器・アクセ（いちばん数が多い）

| 種類 | フォルダ | ファイル名 |
|---|---|---|
| スティック | `assets/images/weapon/stick/` | `stick_001.png` 〜 `stick_165.png` |
| 杖 | `weapon/tue/` | `tue_001.png` 〜 |
| 鞭 | `weapon/wip/` | `wip_001.png` 〜 |
| 短剣 | `weapon/daga/` | `daga_001.png` 〜 |
| 剣 | `weapon/ken/` | `ken_001.png` 〜 |
| 爪 | `weapon/tume/` | `tume_001.png` 〜 |
| 斧 | `weapon/ono/` | `ono_001.png` 〜 |
| メイス | `weapon/mace/` | `mace_001.png` 〜 |
| 鎌 | `weapon/kama/` | `kama_001.png` 〜 |
| 大剣 | `weapon/taiken/` | `taiken_001.png` 〜 |
| 指輪 / 腕輪 / ペンダント / イヤリング / バッジ | `acc/ring/` `acc/bangle/` `acc/pendant/` `acc/earring/` `acc/badge/` | `ring_001.png` 〜 `ring_055.png`（段階＝エリア番号） |

- 番号は **3桁ゼロうめ**（1 → `001`、16 → `016`）。番号＝段階（スプレッドシートの No.）。
- 例外的に別の名前を使いたいときは、データに `image: 'my_sword.png'` と書けばOK。

## その他

| もの | 置き場所 | ファイル名 |
|---|---|---|
| モンスター | `assets/images/monster/` | `monster_001.png`（No.）または データの `image` |
| オブジェクト | `assets/images/object/` | `object_001.png` または `image` |
| 素材 | `assets/images/mat/` | `mat_001.png` または `image` |
| エリア背景 | `assets/images/bg/` | `bg_{テーマ}.png`（例 `bg_forest.png`）。草原だけ `bg_plain.png`。エリア個別なら areas.js の `bg`。ストーリーの背景にもなる（くわしくは `docs/背景画像の追加ガイド.md`） |
| エリアBGM | `assets/bgm/` | `field_{テーマ}.mp3`（例 `field_forest.mp3`）。無ければ草原の曲 |
| 鍛冶マップの島イラスト（任意） | `assets/images/area/` | areas.js の `mapImage` で指定 |
| 効果音 | `assets/se/` | `tap` `open` `close` `change` `hit` `defeat` `craft` `levelup` `timeover` `error` `get` `anvil`（鍛冶のハンマー） ＋ `.mp3`（今は `tools/gen_audio.py` の仮の音） |

## サイズと形式のおすすめ（軽さが大事！）

| もの | おすすめ | 理由 |
|---|---|---|
| 武器・アクセ・素材・モンスター | **256×256px 以内**、背景透明PNG（WebPも可） | 2000枚 × 50KB でも100MB。小さいほど速い |
| 背景 | 縦長 900×1200px 前後、**JPG か WebP**（300KB以内） | 今の背景PNGは1枚3〜7MBあり重い |
| BGM | mp3 128kbps、1曲 1〜2分ループ | |

- `tools/asset_checker.html` で「足りない画像」「大きすぎる画像」を一覧できます。
- ファイル名は **半角英数字・小文字** で。日本語やスペースはさけてください（サーバーで読めないことがある）。
