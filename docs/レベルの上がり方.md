# レベルの上がり方（v1.0.0）

数字はすべて `data/balance.js` で変えられます。

## しくみ
| もの | 式 | 例 |
|---|---|---|
| 1回たたく | **1 EXP** | |
| 倒した（こわした）ボーナス | **5 ＋ エリア番号×5** EXP | エリア1：10、エリア10：55、エリア55：280 |
| 次のレベルまで | **10 ＋ いまのレベル×3** EXP | Lv.1→13、Lv.100→310、Lv.500→1,510 |
| エリアに入れるレベル | **（エリア番号−1）×15** | 平原0、森15、森林30、砂漠1は45 … 魔王城（玉座）810 |
| 敵のHP | そのエリアに来たころの武器の攻撃力 ×（6＋並び順×2） | ちょうどよい武器なら 6〜16回で倒せる |

## めやす（ちょうどよい武器で、1体あたり約11回たたく場合）
| 次のエリア | 必要Lv | ひとつ前のエリアから必要なEXP | 倒す数のめやす | たたく回数のめやす |
|---|---|---|---|---|
| 2 迷いの森林 | 15 | 455 | 約22体 | 約240回 |
| 3 深緑の森 | 30 | 1,140 | 約44体 | 約480回 |
| 4 乾燥した砂漠 | 45 | 1,815 | 約59体 | 約640回 |
| 5 オアシス | 60 | 2,490 | 約69体 | 約760回 |
| 10 常夏の海岸 | 135 | 5,865 | 約96体 | 約1,060回 |
| 19 浮遊島 | 270 | 11,940 | 約113体 | 約1,240回 |
| 28 巨大樹の根 | 405 | 18,015 | 約119体 | 約1,310回 |
| 46 魔導都市 | 675 | 30,165 | 約125体 | 約1,380回 |
| 55 魔王城（玉座） | 810 | 36,240 | 約127体 | 約1,390回 |

- 最初は早く（平原→森は約20体）、後半はエリア1つにつき **約120体** でほぼ一定になります。
- 最後のエリアまで合計：約 **6,000体・66,000回** たたく（1秒に5回たたくと、たたくだけで約3時間40分）。

## 調整したいとき
| こうしたい | 変えるところ |
|---|---|
| エリアの間かくを変える | `areaLevelStep: 15` |
| レベルを上がりやすく | `nextTapExp` の `level * 3` を小さく（例 `* 2`） |
| 倒したときのEXPを増やす | `defeatExp` の `areaNo * 5` を大きく |
| 敵をかたく／やわらかく | `targetHp` の `(6 + indexInArea * 2)` を変える |
